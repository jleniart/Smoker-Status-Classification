In this group project, we created classification models to predict labels for the kaggle smoker dataset (https://www.kaggle.com/datasets/gauravduttakiit/smoker-status-prediction-using-biosignals?resource=download&select=train_dataset.csv).
Team Members: Jack Leniart, Matthew Soria, Francisco Lozano

Tasks:  
1. Preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Baseline Model Creation  
4. Robust model creation (each team member created their own models)

## Setting up environment
Pipfile and Pipfile.lock are present and can be used.  
If you don't want to use Pipenv then a requirements.txt file is available.

Additionally, users will need to install the graphviz executable.  
This can be done with homebrew.  

```
brew install graphviz
```

# Note  
- The output folder contains outputs such as data/graphs needed for the project. These outputs are generated by the jupyter notebooks.
